# ระบบรายงานผลการเรียน โรงเรียนวัดโบสถ์ (ราษฎร์รังสฤษฏ์)

ระบบบันทึกคะแนนและรายงานผลการเรียนระดับอนุบาล–ป.6 พอร์ตมาจากระบบของโรงเรียนบ้านป่าเด็ง (`SATTASAI/students-report`)
ทำงานเป็น **Cloudflare Worker ตัวเดียว + ฐานข้อมูล D1 ของตัวเอง** — ไม่ต้องพึ่งระบบทะเบียนอื่น

วิธีติดตั้งทีละขั้น (ภาษาไทย): [วิธีติดตั้ง.md](วิธีติดตั้ง.md)

## ต่างจากระบบป่าเด็งอย่างไร

| เรื่อง | ป่าเด็ง | วัดโบสถ์ |
|---|---|---|
| บัญชีผู้ใช้ | ใช้บัญชีจากระบบบริหารโรงเรียน | ระบบนี้มีเอง: ติดตั้งครั้งแรกสร้างผู้ดูแลระบบ · ครูสมัครเองได้ · นำเข้าครูจาก Excel พร้อมรหัสผ่านเริ่มต้น (บังคับเปลี่ยนเมื่อเข้าครั้งแรก) · หน้า "บัญชีของฉัน" เปลี่ยนรหัสผ่าน/ออกจากระบบอุปกรณ์อื่น |
| ปีการศึกษา/ภาคเรียน | จากระบบทะเบียน | เมนู "ปีการศึกษาและภาคเรียน": เพิ่มปี ตั้งวันเปิด–ปิดภาค ตั้งปีปัจจุบัน เลื่อนชั้นนักเรียนขึ้นปีใหม่ |
| นักเรียน | จากระบบทะเบียน | นำเข้า/ส่งออกด้วยแม่แบบกลาง (รวมข้อมูลผู้ปกครอง/ที่อยู่) · สร้างห้องใหม่จากไฟล์ได้ · วันเกิดใส่แบบ พ.ศ. ได้ |
| ข้อมูลครู | จากระบบทะเบียน | การ์ดนำเข้า/ส่งออกข้อมูลครู + เมนู "บัญชีผู้ใช้และสิทธิ์" |
| คลังตัวชี้วัด | วางทีละกลุ่ม | + อัปโหลดไฟล์แม่แบบ · ส่งออกทั้งคลัง · ลบทั้งกลุ่ม · ชุดเริ่มต้นใส่ให้ตอนติดตั้ง |
| ตราโรงเรียน | ไฟล์ในเว็บ | ผู้ดูแลอัปโหลดได้ที่ "ตั้งค่าระบบ" |
| สำรองข้อมูล | เฉพาะตาราง gr_* | รวมบัญชีผู้ใช้ นักเรียน ปี/ภาคเรียน ด้วย |
| ดึงข้อมูลจากระบบทะเบียน | มี | ตัดออก |

สิทธิ์การใช้งานเหมือนป่าเด็ง: ครูผู้สอน/ครูประจำชั้น · ทีมวัดผล (grade_admin) · ผู้บริหาร · ผู้ดูแลระบบ · ผู้ชมภายนอก (ดูอย่างเดียว)

## โครงสร้าง

| ที่อยู่ | เนื้อหา |
|---|---|
| `src/index.js` | Worker: เส้นทาง API, ส่งไฟล์หน้าเว็บ, `/logo.png` (ตราที่อัปโหลด) |
| `src/lib/schema.js` | ตารางทั้งหมด — สร้างเองตอนใช้งานครั้งแรก (`CORE_SQL` ตารางพื้นฐาน + `SCHEMA_SQL` ตาราง gr_*) |
| `src/routes/auth.js` | เข้าสู่ระบบ · ติดตั้งครั้งแรก · สมัคร · เปลี่ยนรหัสผ่าน · อุปกรณ์ |
| `src/routes/users.js` | บัญชีผู้ใช้ สิทธิ์ นำเข้า/ส่งออกข้อมูลครู |
| `src/routes/setup.js` | ปีการศึกษา ภาคเรียน เลื่อนชั้น ตราโรงเรียน ขนาดฐานข้อมูล |
| `src/routes/*.js` | รายวิชา สมุดคะแนน ครูประจำชั้น รายงาน ปพ. นักเรียน สำรองข้อมูล ฯลฯ |
| `public/` | หน้าเว็บ (HTML/CSS/JS) · `public/data/` ชุดตัวชี้วัดเริ่มต้น |
| `tests/` | ชุดทดสอบ (`npm test`) · `tests/watbot.test.mjs` ทดสอบส่วนที่เพิ่มสำหรับวัดโบสถ์ |
| `dev/` | เซิร์ฟเวอร์ทดสอบบนเครื่อง (จำลอง D1 ด้วย node:sqlite) |

## คำสั่ง (ต้องมี Node.js 22 ขึ้นไป ไม่ต้อง npm install)

```bash
npm test             # ทดสอบทั้งหมด
npm run dev          # เปิดระบบบนเครื่องแบบฐานข้อมูลว่าง (เหมือนติดตั้งใหม่) ที่ http://localhost:8787
npm run dev:sample   # เปิดพร้อมข้อมูลตัวอย่าง (admin@test.local / test-password-1)
```

## ค่าที่ต้องตั้งบน Cloudflare

| ชื่อ | ชนิด | ค่า |
|---|---|---|
| `DB` | D1 binding (ใน `wrangler.jsonc`) | ฐานข้อมูล D1 ของโรงเรียน — ใส่ `database_id` ให้ตรง |
| `JWT_SECRET` | Secret | ข้อความสุ่มยาว ๆ (ใช้ลงนามการเข้าสู่ระบบ) |
| `TURNSTILE_SECRET_KEY` | Secret (ไม่บังคับ) | **อย่าตั้ง** — หน้าเข้าสู่ระบบของวัดโบสถ์ไม่มีช่องกันบอท ถ้าตั้งจะสมัคร/เข้าสู่ระบบไม่ได้ |

ตรวจการติดตั้ง: เปิด `https://<ที่อยู่เว็บ>/api/health` ต้องได้ `"ok": true`
